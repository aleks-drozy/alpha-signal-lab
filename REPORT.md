## Known limitations

- Survivorship bias in the hand-picked 31-name universe.
- Single asset class (US large-cap equities); no cross-asset generalization
  claim.
- Fixed hyperparameters, not tuned: avoids an obvious leakage vector at the
  cost of not representing a best-effort model.
- Flat 10 bps per side transaction cost model; real costs vary by name, size,
  and market regime.
- 31 names is a small cross-section for daily rank IC and
  decile-spread statistics.

## What would change the answer

- A materially larger, point-in-time-correct universe (removing survivorship
  bias) with the same audit harness.
- Multiple horizons (1-day, 10-day, 21-day) tested with the same
  pre-registration discipline, to see if H=5 is a cherry-picked horizon.
- CPCV (combinatorial purged cross-validation) instead of a single
  walk-forward path, to get a distribution of OOS Sharpe rather than one
  realization.
- A more realistic cost model (size-dependent slippage, borrow cost for
  shorts) instead of the flat 10 bps assumption.

This is read as a stronger form of the same primary NULL finding: the single walk-forward path was not an unlucky low draw from a real positive distribution, since a distribution of comparable, equally valid splits does not clear the bar either. Simplified single-config logit-PBO: fraction of CPCV paths where in-sample rank IC is above the cross-path in-sample median while out-of-sample rank IC is below the cross-path out-of-sample median, log-odds transformed. This is a diagnostic proxy for the one frozen config in this project, not the full multi-strategy Bailey et al. CSCV/PBO framework (which requires a searched candidate set of competing strategies to rank; this project's hyperparameters are fixed a priori, never tuned or searched).
